# 🖥️ 系统监控悬浮窗 (sys_monitor_tauri)

> English documentation: [README_EN.md](README_EN.md)

Windows 桌面系统监控悬浮窗：透明置顶、托盘常驻，实时显示 CPU、内存、GPU、磁盘、网络与进程占用，支持多套显示风格预设与分模块自定义。

## ✨ 功能

- ⚡ **CPU**：占用率环形图 + 实时折线曲线
- 💾 **内存**：占用率进度条 + 已用 / 总量（GB）
- 🎮 **GPU**：每块显卡一行，显示型号、占用率、显存占用
- 💽 **磁盘**：占用率 + 实时读写速度
- 🌐 **网络**：实时下载 / 上传速度
- ⚙️ **进程**：内存占用 Top 8
- 🎨 **显示风格**：4 套预设 + 分模块自定义
- 📌 **系统托盘**：显示 / 隐藏、置顶 / 取消置顶、打开设置、退出
- ⌨️ **全局快捷键**：`Ctrl + Alt + M` 切换显示 / 隐藏
- 👻 **透明窗口**：主窗口整体透明度 20% ~ 100%

## 📦 安装

### 🥇 直接使用

从 [Releases](../../releases) 下载 `sys_monitor_tauri.exe`，放到任意目录双击运行即可，无需安装，配置与运行数据写在用户目录下。

### 🧱 从源码构建

环境要求：

- 🦀 Rust（stable，含 MSVC 工具链）
- 🟢 Node.js 18+
- 🌐 WebView2（Windows 10/11 自带）

```bash
# 安装前端依赖
npm install

# 调试运行（编译 Rust 并打开窗口，支持热更新）
npx tauri dev
```

```bash
# 只构建 exe（推荐）
npx tauri build --no-bundle

# 完整打包（exe + MSI / NSIS 安装包）
npx tauri build
```

产物位置：

| 产物 | 路径 |
|---|---|
| 🚀 exe | `src-tauri\target\release\sys_monitor_tauri.exe`（单文件，可直接运行） |
| 📦 安装包 | `src-tauri\target\release\bundle\` |

> ⚠️ 完整打包需要 WiX 工具链，首次构建会自动下载。

## 🖱️ 使用方法

### 🪟 窗口操作

- 主窗口默认 320×480，可调范围 280×360 ~ 600×900，无边框、透明
- 标题栏整条可拖动；右下角手柄拖动调整窗口大小
- 桌面位置可选：悬浮自由拖动 / 固定右上角 / 固定左上角

### ⌨️ 全局快捷键与托盘

- `Ctrl + Alt + M`：显示 / 隐藏主窗口
- 托盘图标右键菜单：显示 / 隐藏、置顶 / 取消置顶、打开设置、退出

### 🎛️ 设置

点击托盘菜单「设置」打开独立设置窗口，修改后即时生效，主窗口无需重启。

## ⚙️ 配置项

| 配置项 | 说明 |
|---|---|
| 📌 始终置顶 | 主窗口保持在其他窗口之上 |
| 🚀 开机自启动 | 随系统登录自动启动 |
| 🚪 关闭行为 | 最小化到托盘 / 直接退出 |
| 🗺️ 桌面位置 | 悬浮自由拖动 / 固定右上角 / 固定左上角 |
| 🎨 文字颜色 | 7 种预设 |
| 👻 窗口透明度 | 20% ~ 100% |
| 🔠 字号 | 10 ~ 18 |
| 🎭 显示风格 | 4 套预设 + 5 个模块的下拉自定义 |

配置文件位于 `%APPDATA%\com.duan.sys-monitor\settings.json`，字段带默认值，旧版本配置文件向前兼容。

## 🎭 显示风格

设置 →「显示风格」，四个预设按钮一键整套切换：

| 预设 | 布局 | 说明 |
|---|---|---|
| 🌱 默认 | 单列 | CPU 圆环 + 曲线，内存 / GPU / 磁盘进度条，网络双指标卡片 |
| 📈 曲线 | 单列 | 所有模块迷你折线图，便于观察趋势 |
| ✂️ 极简 | 单列 | 每个模块压缩为一行「名称 + 数值」，占用桌面空间最小 |
| 🔲 双列 | 双列网格 | 模块两列排布，窗口变矮，适合贴屏幕侧边 |

分模块自定义：每个模块有独立下拉框（CPU：圆环 / 迷你曲线 / 进度条 / 纯文字；内存、GPU、磁盘：进度条 / 迷你曲线 / 纯文字；网络：默认卡片 / 纯文字 / 迷你曲线）。改动任意下拉即进入「自定义」模式，点击预设按钮则整套套用。

## 📁 目录结构

```
sys_monitor_tauri/
├── index.html            # 主窗口与设置窗口共用（按 window.label 区分）
├── src/
│   ├── main.ts           # 前端逻辑：渲染器调度、曲线历史缓存、设置同步、拖动 / 缩放
│   ├── styles.css        # 样式（字号走 --font-size-base 变量；单列 / 双列布局）
│   └── assets/
├── src-tauri/
│   ├── tauri.conf.json   # 应用配置（窗口、bundle、identifier）
│   ├── Cargo.toml
│   └── src/
│       ├── main.rs       # 入口
│       ├── lib.rs        # 命令注册、托盘、设置窗口、设置变更广播
│       ├── monitor.rs    # 采集主循环 + GPU 独立线程缓存
│       ├── gpu.rs        # GPU 采集（DXGI 枚举 + PDH 计数器）
│       └── settings.rs   # 设置结构体与 JSON 持久化
└── dist/                 # 前端构建产物
```
